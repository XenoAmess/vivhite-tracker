# QQ 分享真机 UX 验证清单

## 前提

- 真机已安装正版 QQ 客户端
- open.qq.com 审核已通过
- App 版本 >= v1.3.1 且已安装

## 测试入口

主界面 → 标题右侧分享按钮。

---

## 场景 1：首次分享（未授权 → 授权 → 真卡片）

| # | 步骤 | 预期 | 异常需记录 |
|---|---|---|---|
| 1.1 | 清数据后打开 App（模拟首次安装），点分享 | 弹引导对话框"QQ 分享需要先授权" | |
| 1.2 | 点"去 QQ 授权" | 跳 QQ 客户端 OAuth 授权页（显示"牢白播了吗 申请使用 你的 QQ 头像和昵称信息"） | |
| 1.3 | 点"同意" | 自动回调到 App，Toast "QQ 授权成功"，然后 QQ 客户端弹出分享好友选择器 | |
| 1.4 | 选一个好友发送 | 消息里包含 B 站直播链接 + bbid=8945059 归因 + 标题"白绮开播啦！" + 封面图 | |
| 1.5 | 接收方看消息 | 显示真卡片（封面图 + 标题 + 描述 + 链接），不是纯文本 | |

## 场景 2：取消授权

| # | 步骤 | 预期 | 异常需记录 |
|---|---|---|---|
| 2.1 | 重复 1.1-1.2 | 弹出 QQ 授权页 | |
| 2.2 | 点"取消" | Toast "已取消授权"，回到 App 主界面，不发分享 | |

## 场景 3：第二次分享（已授权，直接真卡片）

| # | 步骤 | 预期 | 异常需记录 |
|---|---|---|---|
| 3.1 | 场景 1 完成授权后，再次点分享 | **不弹引导对话框**，直接跳 QQ 客户端分享好友选择器 | |
| 3.2 | 选好友发送 | 同 1.4 | |

## 场景 4：普通分享兜底

| # | 步骤 | 预期 | 异常需记录 |
|---|---|---|---|
| 4.1 | 引导对话框中点"普通分享" | 弹系统分享面板（纯文本），可手动选 QQ/Chrome 等 | |
| 4.2 | 在系统分享面板里选 QQ | QQ 客户端接收纯文本消息（无封面、无标题，只有文字链接） | |

## 场景 5：调试信息

请在 `adb logcat` 过滤 `MainActivity | QqSdkSharer` 并执行场景 1-4，把完整日志贴出：

```bash
adb logcat -c
# 执行场景 1
adb logcat -d -t 100 | grep -E "MainActivity|QqSdkSharer"
```

重点关注：
- `D QqSdkSharer: qq login complete:` 后的 JSON（确认 token 已到）
- `D MainActivity: qq auth completed, proceed to share`（确认回调触发）
- 是否有 `E QqSdkSharer:` 或 `E MainActivity: qq auth failed`
